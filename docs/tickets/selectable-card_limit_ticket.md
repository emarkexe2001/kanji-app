Feature Name: 
Card Categories

Feature Description:
I would like as a user to be able to limit the amount of cards I can see at a time based on a user input card limit for example if I enter the number 5.

I should only see 5 cards at a time! The card limit should never be 0, I should always be able to see at least one card, there should also be a maximum amount of cards that I should be able to view at a time as well! For now let's say it's 150.

Feature Requirements / Expected Behaviours:
When I set a card limit I should be able to see the same amount of cards set as the card limit, no more and no less. I should not be able to set a card limit of none or a card limit of higher than 150 for example!

Possible Test Scenarios I would like to see:

When I set a card limit, Card deck size shown should match that limit

When I have a card limit, if I shuffle in a new card the card deck limit should stay the same and an old card should be removed

I should not be able to set a card limit of 0

I should not be able to set a card limit higher than 150!

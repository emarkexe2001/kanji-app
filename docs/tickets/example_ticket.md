Example Ticket

Feature Name: 
Card Shuffle

Feature Description:
I would like as a user to be able to shuffle in a new card from either an existing deck or a deck of choice to add more variety to the amount of cards that I as the user can view. I would like this feature to be a ui button on the bottom left handside of the ui page!

Feature Requirements / Expected Behaviours:
When I press the card shuffle button, a new card should be shuffled into the deck and an old card should be removed, same as tradition card shuffle in a card game where a person can shuffle in a new card by removing / getting rid of an old card,
The default setting for shuffle in a new card should start at 1 and have an ideal limit of 5 - 10 cards that can be shuffled in at a time, I do think it's a great idea to have a limit on the amount of cards that a user can swap in at any time.

Possible Test Scenarios I would like to see:

When I press the card shuffle button, a new card should be shuffled into the deck and an old card should be removed

When I change the card shuffle limit, the amount of cards I should be able to shuffle in should change 

When I add a card shuffle number higher than the limit I should recieve a validation error - say that the card shuffle number exceeds the amount that can be shuffled in at time
